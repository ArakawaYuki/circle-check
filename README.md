# Circle Check

サークル活動への参加、参加費100円、メンバー情報を管理するインストール可能なPWAです。

参加記録画面では、メンバーを過去の参加率が高い順に表示します。

- メンバー・活動記録をJSONファイルへバックアップし、あとから復元できます。
- 活動ごとの体育館代を記録し、参加費収入・支出・収支を集計できます。
- 活動ごとの徴収担当者をメンバーから選択し、活動・収支CSVへ出力できます。

## 公開とインストール

PWAのインストールにはHTTPSでの公開が必要です。GitHub Pages、Cloudflare Pages、Netlifyなどの無料サービスへ、このフォルダの内容をそのまま公開できます。

- Android / Chrome: 画面に表示される「インストール」を押します。
- iPhone / Safari: 共有ボタンから「ホーム画面に追加」を選びます。
- インストール後はオフラインでも利用できます。

データは各端末のブラウザ内に保存されます。アプリ削除やブラウザデータ削除で失われるため、必要に応じてCSVを出力してください。
